# 0008. Партия кухни — одна на блюдо и дату

## Контекст

Кухня готовит блюда для нескольких холодильников сразу. ТЗ требует сводку по блюдам и по холодильникам (R32) и этикетку с кодом партии (R33).

## Решение

Партия одна на блюдо и дату, а не на холодильник. Код партии выглядит как `260311-D01-1`. Статусы партии: `planned`, `confirmed`, `cooked`. Сколько боксов партии идёт в каждый холодильник, отдаётся вместе с партией (`fridgeQty`). Запас на брак в холодильники не раскладывается; в итогах приготовленного он идёт строкой без холодильника. Партии заводятся, когда закрыты все активные холодильники этой даты.

## Почему

Причина выбора в документах не названа, зафиксирован только факт. Отвергнуто явно одно: партия на холодильник. Чем она хуже, документы не говорят.

Сводка, как требует R32, остаётся и по холодильникам, но через раскладку количества внутри партии.

## Последствия

- Код партии на этикетке одинаков для всех холодильников. По нему нельзя определить, в какой холодильник попал бокс.
- «Приготовлено» отмечается один раз на блюдо и дату. Оператор не может загрузить холодильник, пока партии не приготовлены (`batches_not_cooked`).
- Списания по заказам и списания остатка холодильника без заказа считаются раздельно и складываются только в отчёте о приготовленном и списанном (R08).
- Пока открыт приём хотя бы в одном холодильнике даты, партии не заводятся. Тогда кухня работает по пересчитываемой сводке, а не по фиксированному списку.
