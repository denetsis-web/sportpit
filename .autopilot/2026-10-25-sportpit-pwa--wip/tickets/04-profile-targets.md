## Что должно заработать

После входа клиент заполняет анкету цели и получает норму калорий и БЖУ с клетчаткой по формуле Миффлина-Сан Жеора. Для состояний здоровья и возраста вне допустимого диапазона вместо нормы показывается «Обратитесь к врачу». В профиле клиент меняет цель, язык и телефон (с подтверждением новым кодом), видит согласия, выгружает свои данные и удаляет аккаунт.

## Из брифа, дословно

> «Анкета цели: Пол, возраст, рост, вес, цель (похудение / поддержание / набор), активность. Показывает норму калорий и БЖУ»
> «формула Миффлина-Сан Жеора… белок 1,6–2,2 г на кг массы тела… дисклеймер… предупреждение „обратитесь к врачу“»
> «Профиль: Данные цели, язык, телефон, согласия, удаление аккаунта»

## Разделы спецификации

Истории 12–19; Решения по реализации (норма КБЖУ).

## Критерии приёмки

- [ ] `calcTargets` в общем пакете даёт эталонные значения для набора примеров (мужчина и женщина, три цели, четыре уровня активности) и показывает диапазон белка 1,6–2,2 г/кг
- [ ] Для флага состояния здоровья, возраста меньше 18 или больше 80 норма не рассчитывается, виден текст «Обратитесь к врачу», меню остаётся доступным
- [ ] Расчёт не опускается ниже 1200 ккал у женщин и 1500 ккал у мужчин, показывается пометка «минимум безопасного уровня»
- [ ] Рядом с нормой есть дисклеймер «не медицинская рекомендация»
- [ ] Параметры тела не сохраняются без отдельного согласия на данные о здоровье
- [ ] Анкету можно пропустить и вернуться к ней позже из профиля
- [ ] Смена телефона требует кода из SMS, отправленного на новый номер; без подтверждения номер не меняется
- [ ] Выгрузка данных отдаёт JSON с профилем, заказами и оценками текущего пользователя и ничьими больше
- [ ] Удаление аккаунта требует подтверждения; персональные поля стираются, заказы и журнал кредитов остаются без привязки к человеку; повторный вход по тому же номеру создаёт новый аккаунт
