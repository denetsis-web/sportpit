# 03 — Админка: «Лист ожидания» и «Воронка»

**Требования:** R19, R20, R21, R22, R24, R36i, R31, A01
**Зависит от:** 01
**Зона:** `apps/web/src/features/admin/growth/` · `apps/web/tests/admin-growth/` · `packages/shared/src/i18n/growth/`
**Волна:** 2
**Ревью:** нет
**Модель:** обычная

## Что должно заработать

Админ видит в меню админки «Лист ожидания» и «Воронка». В списке — записи с поиском и фильтрами (зал, цель, язык, источник, период), страницей, выгрузкой CSV, отметками пути человека и удалением с подтверждением. В воронке — таблица по источникам за период с долями перехода и уникальными посетителями.

## Из брифа, дословно

> «админ-экран со списком, фильтрами и выгрузкой CSV (как у существующих отчётов), отметка источника.»
> «экран в админке с воронкой по источникам.»

## Разделы спецификации

Истории 28–32, 38–39, 53–54; «Решения по реализации» (админ-экраны, CSV); `interfaces.md` — клиент: админка.

## Критерии приёмки

- [ ] Пункты «Лист ожидания» и «Воронка» есть в меню админки только у `admin`; оператору и кухне — нет, прямой переход даёт экран «нет доступа»
- [ ] Список показывает телефон, имя, зал, цель, язык, источник, ref, campaign, дату и отметки «считал норму / зарегистрировался / купил» (у записей без `anonId` отметок нет)
- [ ] Фильтры (поиск, зал, цель, язык, источник, период) и страницы по 50 работают через запросы к серверу
- [ ] Кнопка «Скачать CSV» ведёт на `/api/v1/admin/waitlist/csv` с теми же фильтрами, как ссылка-загрузка в отчётах; рядом подпись про апостроф перед телефоном
- [ ] Удаление записи — через диалог подтверждения; после подтверждения запись исчезает из списка; при ошибке виден текст ошибки
- [ ] Пустой список — «пока никого»; сбой загрузки — сообщение с кнопкой «повторить»
- [ ] Воронка: период (по умолчанию последние 30 дней), строки по источникам и «всего», колонки событий, доли перехода между этапами, уникальные по этапам; нули без деления на ноль; пусто и сбой — как выше
- [ ] Все подписи — через `t('growth.…')`, ключи ru и ro совпадают; axe-проверка страниц проходит
- [ ] `npm run check:bundle` проходит: код админки остаётся в чанке админки, не в начальном

## Ограничения

Образец — `features/admin/reports/`. Не менять серверный код (он в таске 01); если контракт неудобен, вернуть `BLOCKED` с описанием.
