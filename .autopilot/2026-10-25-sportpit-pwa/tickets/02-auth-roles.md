## Что должно заработать

Клиент входит по номеру телефона и коду из SMS, сессия живёт 30 дней. У пользователя есть роль: клиент, кухня, оператор выдачи, администратор; оператору назначены холодильники. Сервер проверяет роль на каждом закрытом запросе, интерфейс показывает «Нет доступа» там, где доступа нет. Согласия (условия, политика, данные о здоровье) сохраняются с датой и версией. Есть колокольчик с внутренними уведомлениями и каркас админки с меню по ролям. Первого администратора создаёт команда.

## Из брифа, дословно

> «Вход: Телефон + код из SMS»
> «Клиент, Кафе (кухня), Оператор выдачи / курьер, Администратор» (четыре роли с разными правами)
> «Безопасность: TLS, роли и права, журнал действий админов, резервное копирование базы ежедневно»
> «Персональные данные… отдельное явное согласие, политика, возможность выгрузки и удаления»

## Разделы спецификации

Истории 4–6, 8–11, 16, 94; Решения по реализации (API, сессии, уведомления).

## Критерии приёмки

- [ ] Код из 6 цифр живёт 5 минут и допускает не более 5 попыток; верный код создаёт сессию на 30 дней в cookie `HttpOnly; SameSite=Lax`
- [ ] Повторный запрос кода чаще раза в минуту или более 5 в час на номер получает 429 с текстом «подождите N сек»
- [ ] Номер вне формата +373XXXXXXXX и неверный код дают понятные сообщения на выбранном языке, введённый номер остаётся в поле
- [ ] Сбой отправки SMS показывает «Не удалось отправить код, попробуйте ещё раз» и пишет событие `sms_failed`
- [ ] `requireRole` отдаёт 403 пользователю без роли; оператор не может действовать над чужим холодильником
- [ ] Экран «Нет доступа» на RU и RO; меню админки показывает только разделы роли
- [ ] Запросы записи без заголовка `X-Requested-With` отклоняются
- [ ] Согласия сохраняются с датой и версией текста; без согласия на данные о здоровье экран анкеты (таск 04) получает отказ
- [ ] Уведомление создаётся через `notify`, колокольчик показывает непрочитанные и отмечает прочитанными
- [ ] `npm run create-user -- --phone +373… --role admin` создаёт пользователя и не выводит секретов
- [ ] В режиме разработки код доступен в журнале заглушки SMS и никогда не возвращается в ответе API в производственном режиме
