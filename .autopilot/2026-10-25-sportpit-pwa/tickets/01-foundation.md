## Что должно заработать

Рабочий пустой проект: `npm install` и `npm run dev` поднимают сервер и клиент; клиент открывается на телефоне как PWA на русском и румынском, со светлой и тёмной темой; `npm run check` гоняет типы, линтер и тесты. На сервере есть база с миграциями, часы, адаптеры оплаты, SMS и файлов (заглушки), журнал событий системы, проверка здоровья, планировщик и ежедневная резервная копия. Остальные таски подключают свои модули, не правя общие файлы.

## Критерии приёмки

- [ ] `npm install` и `npm run check` проходят на чистом клоне; `npm run dev` поднимает сервер и клиент
- [ ] Миграции применяются при старте и повторный запуск ничего не ломает
- [ ] `Clock` подменяется в тестах; `cutoffFor` считает срок по Europe/Chisinau и корректен в день перевода часов
- [ ] Адаптеры `PaymentGateway`, `SmsSender`, `FileStorage` имеют интерфейс, заглушку и выбор по переменным окружения; значения секретов нигде не читаются в коде кроме конфигурации
- [ ] Автообнаружение из `interfaces.md` работает: тестовый модуль с `routes.ts`, `jobs.ts`, пространством словаря и `routes.tsx` подхватывается без правки общих файлов
- [ ] Тест проверяет, что ключи словарей `ru` и `ro` совпадают, а переключатель языка меняет весь интерфейс и сохраняется
- [ ] `formatMoney` и `formatDate` дают формат Молдовы на обоих языках (лей, дата дд.мм.гггг)
- [ ] Манифест PWA, иконки, service worker, метки для iOS; меню и оболочка открываются из кэша без сети с понятным баннером «Нет связи»
- [ ] Светлая и тёмная темы следуют за системой с переключателем; компонент подсказки установки на экран «Домой» существует
- [ ] Общие компоненты `ui` проходят автопроверку доступности без критических нарушений; контраст AA, кнопки не меньше 44 px
- [ ] Начальный JS клиента не больше 250 КБ gzip, админка в отдельном чанке (проверка в `npm run check`)
- [ ] `/api/health` отвечает; `logEvent` пишет события, сбой адаптера SMS или оплаты записывается и считается за 24 часа
- [ ] Резервная копия базы создаётся задачей по расписанию (03:00) и по команде, хранится 14 копий
- [ ] `README.md` описывает установку, запуск, переменные окружения и проверку; `.env.example` содержит только имена
